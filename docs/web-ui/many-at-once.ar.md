# كثير دفعة واحدة

حدّد عدة عمليات، وانقلها أو أرشفها أو اوسمها أو احذفها معًا.

## التحديد

- **في الجدول:** مربع اختيار لكل صف، وواحد في الترويسة لكل الصفوف المعروضة، وshift مع النقر
  لمجموعة متتالية.
- **على اللوحة:** Ctrl/⌘ مع النقر على بطاقة، أو اضغط x عليها. وEscape يُلغي التحديد.
- والشركات والأشخاص والملفات لها مربعات الاختيار نفسها، لوسمها أو إزالة وسمها أو حذفها معًا.

## ما يمكنك فعله

فيعرض شريط:

- نقل إلى (مرحلة، أو مسار فيها)؛
- أرشفة… (سبب وملاحظة واحدة للجميع)؛
- استئناف؛
- إضافة وسم… وإزالة وسم…؛
- الإجراء التالي…؛
- حذف….

وسحب بطاقة محدّدة على اللوحة يجلب الأخرى معها (إلى عمود، أو مسار، أو الأرشيف). وكل تغيير كله أو لا
شيء، ويُسجَّل على كل عملية، وتعرض رسالة منبثقة التراجع.

## من سطر الأوامر

يفعل `POST /api/processes/bulk` ذلك لواجهة البرمجة، ويقبل سطر الأوامر عدة عمليات معًا:

```sh
hunt move globex,initech screening
hunt archive tag:agency role-filled
hunt move stage:Applied interviewing
```
