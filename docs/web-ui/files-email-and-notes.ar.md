# الملفات والبريد والملاحظات

مستنداتك وإصداراتها، والرسائل الخاصة بكل عملية، وملاحظات عن البحث نفسه.

## الملفات

المستندات وإصداراتها. المستند سيرة ذاتية، أو خطاب تقديم، أو ملف أعمال، أو مرجع، أو شهادة أو كشف
درجات، أو لقطة شاشة، أو وصف وظيفة، أو مهمة منزلية، أو عرض، أو عقد، أو اتفاقية عدم إفصاح، أو تحقّق
من الخلفية، أو حق العمل أو هوية، أو مورد للمرشح، أو ملاحظات، أو غير ذلك. والقائمة تُصفّى بالنوع،
ويُخمَّن نوع الملف الجديد من اسمه.

- أسقط الملفات في أي مكان من الصفحة، أو اخترها (منطقة الإسقاط تحت القائمة): الملف المسمّى كمستند
  يصير إصداره التالي، وأي شيء آخر يصير مستندًا جديدًا، يُخمَّن نوعه من الاسم.
- أسقط على صفّ لتضيف إصدارًا إلى ذلك المستند.
- يعرض المستند إصداراته بجانب معاينة: ملفات PDF في عارض المتصفح، والصور، والنصوص. والأنواع الأخرى
  تعرض التنزيل.
- وسم الإصدارات («rust-focused»)، وانظر مع أي العمليات أُرسل كلٌّ منها. والعملية تسجّل أي الإصدارات
  أُرسلت معها، وتعاينها أيضًا.

## البريد

كل عملية تحتفظ بالرسائل الخاصة بها. في لوحة «الرسائل» فيها:

- أسقط ملفات `.eml` (في Gmail: ⋮ ← تنزيل الرسالة)، أو اخترها؛
- أو الصق رسالة (في Gmail: ⋮ ← إظهار الأصل ← نسخ إلى الحافظة؛ ولصق الصفحة كلها يعمل أيضًا).

كلٌّ تعرض من ومتى والموضوع وبدايتها، وتُفتح على النص كله، وترتبط بها في Gmail. والبطاقات تعدّها.

تسجيل الدخول إلى Gmail ومزامنته، ومطابقة البريد بالعمليات تلقائيًا، مبنية لكنها معطّلة الآن: `GMAIL`
في `src/web/app.js`.

## الملاحظات

ملاحظات عامة، عن البحث لا عن طلب واحد (ما تريده تاليًا، والأسئلة التي تطرحها): قابلة للبحث والوسم،
وتُعدَّل في مكانها.
