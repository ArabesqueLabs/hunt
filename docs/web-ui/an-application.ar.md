# صفحة الطلب

لكل طلب صفحة خاصة (`/applications/ID`): تفتحها بطاقة على اللوحة وصفٌّ في الطلبات كلاهما.

## ما تعرضه

تُقرأ أولًا، من الأعلى إلى الأسفل:

- مرحلته (شريط خطوات)، وما إذا كان مؤرشفًا؛
- الوظيفة: الموقع ونمط العمل ونوع التوظيف أولًا، ثم الأجر (بالجنيه أولًا، وتحته العملة الأصلية
  والسعر؛ والمكافأة والأسهم)، ثم رابط الإعلان والمصدر ومتى تقدّمت؛
- الخط الزمني: خطوات المقابلات (متى، وبأي شكل، ومع من، والملاحظات) وما حدث، بترتيب التاريخ. و«مع
  من» يختار أشخاصًا من الأشخاص، أو يقبل اسمًا جديدًا يصير شخصًا (في شركة الطلب) حين تُحفظ الصفحة؛
  وعند القراءة، أسماؤهم روابط إليهم؛
- ملاحظاتك؛
- عن الوظيفة: إعلاناتها، كلٌّ معروض كرسالة بريد (من أين، ومتى نُشر ومتى يُغلق، أو متى قُرئ آخر مرة،
  ثم العناوين والقوائم والروابط في مربعه الخاص؛ وفتح ↖، وتحديث، وإزالة لكلها عدا الرئيسي)؛
- الأشخاص، ببريدهم وهاتفهم للنقر (للمراسلة أو الاتصال)؛ والرسائل، محادثاتٍ (بمحادثة Gmail، أو
  بالموضوع)، مطويّة حتى تُفتح، كل رسالة بوقتها؛ والملفات المرسلة؛
- الشركة، مطويّة حتى تُفتح، وسجل التغييرات؛
- الوسوم، ثم الاستيراد من رابط… وأرشفة… وحذف في الأسفل.

كل قسم يُطوى من ترويسته، ويبقى كما تركته.

## الإضافة والتعديل

- عند القراءة، لا تعرض الصفحة نماذج: «+ إضافة شخص» و«+ إضافة رسالة» و«+ إرسال ملف» تفتح نماذجها،
  و«+ إضافة خطوة» أو «+ إضافة حدث» أو «+ إضافة ملاحظة» تبدأ التعديل هناك.
- و**تعديل** يحوّل الصفحة إلى نموذج واحد: غيّر أي شيء، وانقل المرحلة، وأضف خطوات وعناصر خط زمني أو
  أزلها، ثم **حفظ التغييرات** (⌘S) أو **تجاهل**. والمغادرة مع تغييرات غير محفوظة تسأل أولًا.
- والأشخاص والرسائل والملفات تُحفظ حالما تُضاف أو تُزال، في الوضعين.
