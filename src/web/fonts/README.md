# Fonts

The fonts hunt serves, as Arabesque, the Arabesque Labs design system, has
them: Google Fonts' latin subsets of Jost and Newsreader, its arabic subset of Amiri, and
IBM's own complete files of IBM Plex Sans Arabic (github.com/IBM/plex,
@ibm/plex-sans-arabic@1.1.0), unchanged: its licence reserves the name
"Plex", so it isn't subset here. Each family is under the SIL Open Font License 1.1; its
licence, with its copyright, is beside it.

| Family | Files | Licence |
|---|---|---|
| Jost | `jost.woff2` | [OFL-jost.txt](OFL-jost.txt) |
| Newsreader | `newsreader.woff2`, `newsreader-italic.woff2` | [OFL-newsreader.txt](OFL-newsreader.txt) |
| IBM Plex Sans Arabic | `plex-arabic-400.woff2`, `-500`, `-600` | [OFL-ibmplexsansarabic.txt](OFL-ibmplexsansarabic.txt) |
| Amiri | `amiri.woff2` | [OFL-amiri.txt](OFL-amiri.txt) |

The container image carries these licences in `/usr/share/doc/hunt/fonts/`.
